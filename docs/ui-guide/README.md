# UI操作レクチャー資料（バニラJS / HTML）

フロントエンドUIの「操作名称」と「動作」を対応づけるための教材。依存ライブラリなし、各HTMLをブラウザで開くだけで動く。

| # | ファイル | 内容 | 状態 |
|---|---|---|---|
| 01 | `01-ui-operations-catalog.html` | UI操作の分類リスト（A:一般 / B:カスタマイズ / C:プロ志向、通し番号付き） | 完成 |
| 02〜 | （予定） | 各操作の動くデモ（パン、ズーム、フェード、慣性 など） | 未着手 |

## 使い方
ファイルをダブルクリックしてブラウザで開く。サーバ不要。
