UI操作レクチャー資料（バニラJS / HTML）

フロントエンドUIの「操作の名称」と「実際の動き」を対応づける教材。依存ライブラリなし。すべてのページはこのフォルダをそのままブラウザで開けば動く（サーバ不要）。

おすすめの順路

基礎知識 土台

座標系、イベントの発火順、transform と left/top の違い、passive/touch-action、そして「混同しやすい用語の対比表」。全デモの前提になる。

カタログ 索引

86項目の名称・英語名・一言説明・実装手段。検索と層フィルタ。各項目から動くデモへ飛べる。

A：一般的なUI操作（01〜22） A

スクロール、パン、ズーム、DnD、フェード、モーダル…。ブラウザ標準で賄える基本。

B：カスタマイズ性の高いUI（23〜42） B

仮想スクロール、慣性、スプリング、FLIP、並べ替え、Undo/Redo…。標準挙動を自前で制御する。

C：プロ志向のUI（43〜62） C

無限キャンバス、ミニマップ、ノードエディタ、データグリッド、Electron連携…。ツール系アプリの高度操作。

D：業務アプリの設計パターン（71〜86） D

大規模グリッド、検索・フォームの型、バッチ操作、競合解決、オフライン、ドッキング、マルチウィンドウ…。A〜Cの部品の組み合わせ方。

E：演出・体感の上位効果（63〜70） E

シェアードエレメント遷移、スタガー、マイクロインタラクション、ぼかしと性能…。最後に、控えめに。

アクセシビリティ 検査

キーボード順路の可視化、名前のない操作要素の検出、コントラスト計算、aria-live、環境設定の検出、チェックリスト。

名称当てクイズ 確認

説明文から名称を4択で当てる。間違えた項目はデモへのリンクが残る。層と問題数を選べる。

練習課題 演習

デモのコードを改変して仕様を満たす12問。ヒントと解答例つき。
