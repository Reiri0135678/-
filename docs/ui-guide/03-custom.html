B層は「ブラウザ標準の挙動を自分で制御する」領域。Pointer Events・Observer系・requestAnimationFrame の3つが道具の中心になる。

23仮想スクロール Virtual scroll / Windowing

10万行あっても DOM は「見えている行＋少し」だけ作る。スクロール位置から開始行を割り算で求め、上に「行高×開始行」の余白を置いて位置を合わせる。

操作：スクロールしても DOM 行数は約20のまま。

24スティッキー（固定ヘッダー / 固定列） Sticky header / column

スクロールしても見出しが留まる。position: sticky だけで実現でき、JSは不要。左上のセルは top と left の両方を指定して両方向に固定する。

操作：表を縦横にスクロール。

25スクロールスナップ Scroll snap

スクロールを止めた時、区切り位置に吸着する。CSSだけで「カルーセル」「ページ単位の閲覧」ができ、慣性・タッチ対応もブラウザ任せ。

操作：横にスクロール（Shift+ホイール or トラックパッド）。どこで止めてもカードの先頭に揃う。

26パララックス Parallax

前景と背景を異なる速度で動かして奥行きを出す。実装は「スクロール量 × 係数」を transform に入れるだけ。業務アプリでは酔いやすいので控えめに。

操作：枠内をスクロール。背景の丸は 0.3 倍の速度で動く。

27スクロール連動アニメーション Scroll-driven reveal

要素が画面に入った瞬間をトリガーにする。scroll イベントで毎回位置計算せず、IntersectionObserver に「入った／出た」だけ教えてもらう。

操作：枠内をスクロール。入ったカードがフェード＋上昇で現れる。

28慣性 / モーメンタム Inertia / Momentum

指を離した後も速度を保ちながら減速して止まる。「離した瞬間の速度」を記録し、毎フレーム速度に減衰係数（0.95など）を掛けて位置を進める。パン（02）にこれを足すと「気持ちよさ」が出る。

操作：方眼を素早くドラッグして離す。壁で跳ね返る。

29スプリング物理 Spring animation

目標との差に比例した力（バネ）と速度に比例した抵抗（減衰）で動かす。時間固定のトランジションと違い、途中で目標が変わっても不自然にならない。

操作：枠内をクリック。連続でクリックして途中変更の滑らかさを見る。剛性・減衰を変えてみる。

30FLIPアニメーション First-Last-Invert-Play

レイアウトが変わる（並べ替え・追加・削除）ときの定石。①変更前の位置を測る（First）②DOMを変える③変更後の位置を測る（Last）④差分だけ transform で元の位置に戻す（Invert）⑤transformを0へアニメーション（Play）。

操作：シャッフル。DOMは一瞬で並び替わっているが、見た目は滑らかに移動する。

31ビュー遷移 View Transitions API

DOM更新の「前」と「後」をブラウザがスナップショットし、自動でクロスフェードする。view-transition-name を付けた要素は位置・サイズの移動もアニメーションする。未対応ブラウザでは即時切替にフォールバック。

操作：「一覧」と「詳細」を切り替える。画像だけは同じ名前を持つので位置が繋がる。

32ドラッグ並べ替え Sortable / Reorder（Pointer Events自作）

HTML標準DnD（08）を使わず Pointer Events で自作すると、タッチ対応・見た目の完全制御・FLIPとの併用ができる。掴んだ要素は transform で追従させ、他要素との重なりで挿入位置を決める。

操作：行をドラッグして並べ替え。

33分割パネル / ドッキング Split pane / Dock layout

境界（ガター）をドラッグして領域比率を変える。IDE風レイアウトの基礎。grid の列幅を書き換えるだけで、中身のレイアウトは自動で追従する。慣習：最小幅で止まる、ガターのダブルクリックで初期比率に戻す。

操作：中央の縦棒をドラッグ。ダブルクリックでリセット。

34キーボードナビゲーション Roving tabindex

ツールバーやグリッドの中は矢印キーで移動し、Tab は「グループごと」に抜ける。実現方法は「今の項目だけ tabindex=0、他は -1」に付け替え続けること（roving = 巡回）。

操作：最初のボタンにフォーカス（クリック）→ ←→HomeEnd。Tab で次のグループへ一気に抜ける。

35ショートカットキー Hotkeys

キー組合せで機能を呼ぶ。要点：①ブラウザ既定動作を preventDefault() で止める ②入力欄にフォーカス中は単独キーのショートカットを無効化 ③Mac は metaKey、Windows は ctrlKey。

操作：このページ上で Ctrl/⌘+S、Ctrl/⌘+K（36へ）、単独 N。入力欄内で N を打つと無視される。

-

36コマンドパレット Command palette

Ctrl+K で検索窓を開き、機能を文字で呼び出す。あいまい検索 → 矢印で選択 → Enter で実行。機能が増えてもメニューを掘らずに済む。

操作：ボタンか Ctrl/⌘+K。「csv」「削」などで絞り込み。

-

37アンドゥ / リドゥ Undo / Redo

操作履歴を積んで巻き戻す。ここは「状態のスナップショット」方式（過去の状態を丸ごと配列に保存）。単純で確実。状態が大きいなら「逆操作コマンド」方式を検討する。

操作：丸を追加／色替え → Ctrl/⌘+Z / Ctrl/⌘+Shift+Z またはボタン。

38インライン編集 Inline editing

表示中の値をその場で編集状態に切り替える。終了経路を3つ揃える：Enter=確定、Esc=取消、フォーカスが外れた=確定。どれか欠けると「戻れない」UIになる。

操作：セルをダブルクリック（またはフォーカスして Enter）。

39カスタムコンテキストメニュー Custom context menu

右クリックで独自メニューを出す。contextmenu イベントを止め、クリック位置に出す。画面端では反転して枠内に収める。

操作：灰色の領域で右クリック（タッチは長押し）。端の方で試す。

40進捗表示 Progress（determinate / indeterminate）

完了率が分かるなら確定型（バー）、分からないなら不定型（流れるだけ）。長い処理には必ずキャンセル手段を添える。AbortController で中断できる作りにしておく。

操作：開始 → 途中でキャンセル。

待機

41ジェスチャー競合の解決 touch-action / 方向ロック

「縦にスクロールしたいのか、横にスワイプしたいのか」をブラウザと取り合わない。touch-action: pan-y で縦はブラウザに任せ、横は自分で取る。さらに初動数pxの方向で「今回はどちらか」を確定（方向ロック）する。

操作：カードを横にドラッグ（削除アクションが出る）。縦に動かすと枠がスクロールする。タッチ端末で差がよく分かる。

42モーション低減対応 prefers-reduced-motion

OS設定で「視覚効果を減らす」を選んだユーザーには、動きを短縮・省略する。CSSのメディアクエリ1つで全アニメーションを止められる。JSからも matchMedia で判定できる。

操作：ボタンで動かす。OS設定を変えるとこのページの動きが止まる（右の表示で確認）。
