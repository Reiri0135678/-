⌂ 入口カタログプレイグラウンド
この資料一式（- ファイル）を、外部ファイルを一切参照しない 1 枚の HTML にまとめる。Node もビルドツールも使わず、このページの JavaScript だけで生成する。できたファイルはダブルクリックで開け、そのまま配布・持ち出しができる。

1. 元のファイルを読み込む

どちらか一方でよい。フォルダ選択はファイルを開いただけの状態（file://）でも使える。このページから読み込むはローカルサーバ経由（http://）でだけ使える。

2. 生成する

読み込んだ内容を assets/bundler.js がそのまま 1 枚の HTML に組み立てる（Node 版の npm run build:docs と同じ処理・同じ結果）。

仕組み

ページごとに「完全な HTML 文書」を組み立てて iframe の srcdoc に入れて表示する。元ファイルと同じ順序でスタイルとスクリプトが動くのでデモはそのまま動き、ページ間で CSS が衝突しない。ページ内のリンクは iframe の中で横取りして親に伝え、親が該当ページへ切り替える。実装は assets/bundler.js（組み立て）と assets/standalone-shell.js（生成物の中で動く部分）の2つだけ。

注意：docs/ui-guide だけでなくリポジトリのルートを選ぶと、ui-kit の部品と実例アプリも収録される。フォルダ選択ではブラウザが確認ダイアログを出すが、ファイルはどこにも送信されず、すべてこのページの中だけで処理される。
