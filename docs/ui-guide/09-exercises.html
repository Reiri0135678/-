課題7：慣性パンにする2

02 パン に 28 慣性 を合成し、離した後も滑って止まるようにする（壁なし、減衰 0.92）。

対象：02 ▶ プレイグラウンドで開く ＋ 28　ヒント：pointermove で直近の速度（px/ms）を記録。pointerup で rAF ループを開始し、毎フレーム tx += vx、vx *= 0.92。次の pointerdown でループを止める。

解答例
let vx = 0, vy = 0, last = null, raf = 0;
view.addEventListener('pointerdown', e => { cancelAnimationFrame(raf); dragging = {...}; last = { x: e.clientX, y: e.clientY, t: performance.now() }; });
view.addEventListener('pointermove', e => { if (!dragging) return;
  const now = performance.now(), dt = Math.max(1, now - last.t);
  vx = (e.clientX - last.x) / dt * 16; vy = (e.clientY - last.y) / dt * 16; last = { x: e.clientX, y: e.clientY, t: now };
  /* tx, ty 更新は元のまま */ });
view.addEventListener('pointerup', () => { dragging = null;
  const step = () => { tx += vx; ty += vy; vx *= 0.92; vy *= 0.92; world.style.transform = `translate(${tx}px, ${ty}px)`; if (Math.abs(vx) + Math.abs(vy) > 0.1) raf = requestAnimationFrame(step); };
  raf = requestAnimationFrame(step); });
