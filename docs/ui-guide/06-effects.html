63シェアードエレメント遷移 Shared element transition

一覧の行が「同じ物として」詳細画面へ拡大移動する。View Transitions（31）で、遷移する瞬間だけクリックした要素に view-transition-name を付ける。全行に同じ名前を付けると衝突して失敗するので、動的に付け外しするのが要点。

操作：カードをクリック→詳細へ。「戻る」で逆再生。非対応ブラウザは即時切替。

64スタガーアニメーション Stagger

複数要素を数十msずつ遅らせて順に出す。「一斉にドン」より軽く見え、視線を上から下へ誘導できる。CSSなら animation-delay: calc(var(--i) * 40ms)、JSなら WAAPI の delay。要素数が多いときは合計時間が伸びすぎないよう上限を設ける。

操作：再生。間隔を変えて印象の違いを見る。

間隔 40ms

65スケルトン → 実データのモーフィング Skeleton morph

スケルトン（22）から本物の内容へ切り替わる瞬間に「ガタつき」が出るのを防ぐ。①スケルトンと本物を同じ位置に重ね、クロスフェードする ②高さが変わるならFLIP（30）の高さ版で滑らかに伸縮する。

操作：再読込。「ガタつき版」と比べる。

66マイクロインタラクション Micro-interactions

操作に対する「小さな返事」。チェックのバウンス、保存ボタンの「送信中→完了」の形状変化、いいねの弾み。ルール：150〜300ms、ユーザーの操作の直後に、操作したその場所で起きる。装飾ではなく「受け付けた」の合図。

操作：それぞれ押す。

67ジェスチャー連動の物理 Interactive back swipe

画面遷移を「アニメーション再生」ではなく「指の位置に追従」させ、離した時点で完了か取消かを決める（iOSの戻る操作）。ドラッグ量を0〜1の進捗に変換し、離したら閾値（40%）と速度で判定、残りはスプリング（29）で流す。

操作：詳細画面の左端からドラッグ。途中で戻すとキャンセルされる。

69ぼかし / グラスモーフィズム backdrop-filter と性能

半透明パネルの背後をぼかす backdrop-filter: blur()。見栄えは良いが、背後が動くたびに毎フレーム再計算されるためGPUが弱い端末では重い。実機で計測し、必要なら blur を外して単なる半透明にする。

操作：ぼかしON/OFFを切り替えて、右上のフレーム時間を比べる（差が出ない端末なら採用してよい）。

70ダークモード切替のクロスフェード Theme transition with View Transitions

テーマ切替時に全画面がパッと変わるのを、View Transitions で滑らかにする。標準は全体クロスフェード。::view-transition-new(root) に clip-path: circle() をアニメーションさせると「クリック位置から広がる」演出になる。テーマ自体は data-theme 属性と CSS 変数で。

操作：ボタンを押す（押した位置から広がる）。このデモ枠内だけがテーマ切替の対象。
