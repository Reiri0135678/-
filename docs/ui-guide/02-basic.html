操作：枠内でホイール／ドラッグ／ボタン。右の数値が scrollTop。

02パン Pan

操作：方眼をドラッグ。transform: translate() に差分を足すだけ。

03ズーム Zoom

表示倍率を変える。ここでは「枠の中心」を基準に拡大縮小する最も単純な形。ホイール位置を基準にする本格版は 44。

操作：枠内でホイール（トラックパッドはピンチ＝ctrlKey 付き wheel）、またはボタン。

04クリック / タップ Click / Tap

最も基本の操作だが、1回の操作で複数のイベントが順に発火する。マウスとタッチで順序・種類が違うことを見て覚える。

操作：青い箱をクリック／タップ。発火順がログに出る。pointer* を使えば入力装置を問わず1系統で書ける。

操作：左はダブルクリック。右は500ms押し続ける（動かすとキャンセル）。

06ホバー Hover

ポインタが要素上にある状態。タッチ端末には「ホバー」が存在しないため、ホバーでしか出ない情報を作らない。

操作：箱にポインタを乗せる。@media (hover: hover) でホバー可能な環境か判定できる。

hover

07フォーカス Focus

キーボード入力を受け取る要素は常に1つ。Tabで順に移動する。:focus-visible はキーボード操作時だけ枠を出すので、マウス時に枠が邪魔にならない。

操作：最初のボタンを押した後 Tab / Shift+Tab。div は tabindex="0" を付けて初めてフォーカスできる。

div(tabindex=0)

10リサイズ Resize

つまみ（ハンドル）をドラッグして大きさを変える。サイズ変化の検知は ResizeObserver が正解（window.resize は要素の変化を拾えない）。

操作：右下の角をドラッグ。最小サイズで止まる。

パネル

11選択 Select（単一 / Ctrl追加 / Shift範囲）

項目を選ぶ。Excelやエクスプローラと同じ修飾キー慣習（Ctrl=追加/解除、Shift=範囲）に合わせると業務ユーザーは説明なしで使える。

操作：行をクリック。Ctrl/⌘ や Shift を押しながらクリック。

選択: なし

12フェードイン / フェードアウト Fade in / out

不透明度（opacity）を時間で補間する。最も安価で自然な出現・消失。注意点は「opacity:0 でも要素はそこに在る（クリックできる）」こと。消した後は display:none か visibility:hidden にする。

操作：トグル。transitionend で「完全に消えた瞬間」を拾って非表示化している。

state: visible
通知パネル

13スライドイン / スライドアウト Slide in / out

画面端から滑り込む。left や margin ではなく transform を動かす（レイアウト計算が走らず滑らか）。ドロワー・サイドパネル・通知の基本。

操作：ボタンで右からパネルが出る。背景クリックでも閉じる。

設定パネル

transform: translateX(100%) → 0

14トランジション / イージング Transition / Easing

状態AからBへ「時間をかけて」変える仕組みがトランジション。その途中の速度配分がイージング。UIでは ease-out（速く出て静かに止まる）が基本。ease-in は「反応が遅い」と感じさせる。

操作：ボタンで4つの玉を同時に走らせ、違いを見る。

背後の操作を止めて前面で確認・入力させる。標準の <dialog> を showModal() で開くと、背景の暗幕・Escで閉じる・フォーカス閉じ込め・背面の不活性化が全部ついてくる。

操作：開いて Esc や暗幕クリックで閉じる。戻り値は returnValue で受け取る。

16トースト / スナックバー Toast / Snackbar

操作結果を隅に短時間表示し、自動で消える。作業を中断させない通知。読み上げ対応のため aria-live を付ける。

操作：連打すると積み上がる。ホバー中は消えない（読む時間を確保）。

17ツールチップ / ポップオーバー Tooltip / Popover

補足情報を小さく浮かせて出す。難しいのは位置決め：画面端では上下・左右を反転させる。getBoundingClientRect() で対象の位置を取り、はみ出すなら反対側へ。

操作：ボタンにホバー／フォーカス。右端のボタンでは反転する。

操作：見出しをクリック。

19タブ Tabs

同じ領域を複数のビューで切り替える。WAI-ARIAの作法：タブ列は role=tablist、Tabキーでは選択中タブに止まり、←→ で隣へ移動。

操作：クリック、またはタブにフォーカスして矢印キー。

20ドロップダウン / メニュー Dropdown / Menu

ボタン押下で選択肢を展開する。自作するときの必須処理は3つ：外側クリックで閉じる、Escで閉じる、項目選択で閉じる。

操作：ボタンを押し、外をクリックや Esc で閉じる。

選択: -

21ページネーション / 無限スクロール Pagination / Infinite scroll

大量データを分割して取得・表示する2方式。ページ番号は「位置が分かる」、無限スクロールは「操作が要らない」。kintoneのレコード取得（offset/limit、またはカーソルAPI）はこの下で動く。

操作：左は番号で切替。右は末尾までスクロールすると IntersectionObserver が「番兵」を検知して追加読み込みする。

読込: 0件

22ローディング表示 Loading / Skeleton / Spinner

待ち時間を可視化する。スピナーは「何か待っている」しか伝えないが、スケルトン（内容の形の灰色）は「何が来るか」を先に見せるので体感が速い。

操作：再読込で2秒待ち。どちらの待ち方が楽か比べる。
