層意味実装の主な手段
A 一般ほぼ全てのアプリで使う基本操作・演出。ブラウザ標準で大半が賄えるCSS / 標準DOM API
B カスタマイズ標準挙動を自前で制御・拡張するもの。業務アプリの「使いやすさ」はここで決まるPointer Events / Observer系 / rAF
C プロ志向エディタ・キャンバス・グリッド等、ツール系アプリに必要な高度操作座標変換 / 状態機械 / Canvas / Electron連携
D 業務アプリ設計A〜Cの部品を組み合わせた設計パターン（第3弾・第4弾）。番号は提案リストの通り状態オブジェクト集約 / localStorage / BroadcastChannel / History API
E 演出・体感見た目の気持ちよさを作る上位効果（第4弾）。短く・控えめに・止められるようにView Transitions / WAAPI / animation-timeline / backdrop-filter
